## How to use it
1. Clone the repo (```git clone https://github.com/Vaniones/SteamRaider.git```)
2. CD into the directory (```cd SteamRaider```)
3. Create a file called config.json
4. Paste this text into the config, replace the shit:
   ```
   {
     "user": "<STEAM_USERNAME>",
     "pass": "<STEAM_PASSWORD>",
     "message: "haha u have been raided!!!"
   }
   ```
